# اسبيرك | Espairak — النسخة الأولية لتطبيق أندرويد

هذه حزمة **مصدر مشروع Flutter** وليست ملف APK جاهزاً للتثبيت.

## ما الذي يعمل الآن؟
- واجهة عربية RTL.
- عرض منتجات تجريبية لزيوت السيارات وقطع الغيار.
- البحث بالاسم أو القسم أو اسم المتجر.
- تصفية حسب المدينة.
- ترتيب الأسعار من الأقل إلى الأعلى أو العكس.
- تفاصيل المنتج.
- إضافة منتج تجريبي أثناء تشغيل التطبيق.

## ما الذي لا يعمل بعد؟
- لا توجد قاعدة بيانات مشتركة.
- حسابات التجار وتسجيل الدخول غير مفعّلة.
- المنتجات التي يضيفها المستخدم محفوظة في ذاكرة الجلسة فقط.
- لا يوجد تواصل فعلي مع المتاجر أو تحديث مباشر للأسعار.
- أسماء المتاجر والأسعار بيانات تجريبية؛ لا تستخدمها باعتبارها عروضاً حقيقية.

## تحويل المشروع إلى APK

### الطريقة 1: عبر كمبيوتر
1. ثبّت Flutter وAndroid Studio على الكمبيوتر.
2. أنشئ مشروع Flutter فارغاً باسم `espairak` بالأمر:
   `flutter create espairak`
3. استبدل ملف `pubspec.yaml` وملف `lib/main.dart` في المشروع بالملفين الموجودين في هذه الحزمة.
4. افتح الطرفية داخل مجلد المشروع وشغّل:
   `flutter pub get`
5. جرّب التطبيق:
   `flutter run`
6. لإنشاء ملف APK:
   `flutter build apk --release`
7. ستجد الملف عادة في:
   `build/app/outputs/flutter-apk/app-release.apk`

### الطريقة 2: إذا كنت تستخدم الهاتف فقط
تحتاج إلى خدمة بناء سحابية تدعم Flutter. عادةً سترفع المشروع إلى مستودع Git وتربطه بخدمة البناء، ثم تطلب بناء Android APK. قد تتطلب هذه الخدمات حساباً وإعدادات إضافية، وبعضها مدفوع. لا ترفع مفاتيح سرية أو بيانات عملاء إلى مستودع عام.

## الخطوة التالية قبل إطلاق التطبيق
يجب إعداد مشروع Supabase وقاعدة بيانات للمنتجات والمتاجر وحسابات التجار، ثم ربط التطبيق بها. لا تضع مفاتيح الإدارة السرية داخل تطبيق الهاتف. استخدم فقط إعدادات العميل العامة مع سياسات Row Level Security صحيحة، واختبر صلاحيات كل دور قبل الإطلاق.

## ملاحظة
هذا مشروع أولي قابل للتطوير، وليس نسخة إنتاجية جاهزة للنشر على Google Play. قبل النشر نحتاج إلى اختبار الأجهزة، الأمان، سياسة الخصوصية، وإدارة بيانات المتاجر والأسعار.
